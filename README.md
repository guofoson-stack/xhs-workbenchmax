# 小红书爆款工作台（本地版）

每天把找到的小红书爆款拆成「积木」存进库里。做新考试时，工作台从库里自动搭配标题、封面和正文，一次生成好几版，封面直接出图。

**用法很简单：** 找一台电脑当主机，双击启动，同事在浏览器里打开就能用。不需要服务器、不需要数据库账号、不需要备案，所有数据都存在这台电脑上。

```
入库拆解 → 爆款库 → 录考情 → 一键生成（标题 + 正文 + 封面图）→ 发布后回填数据 → 好积木自动加分
```

---

## 一、第一次安装（约 10 分钟，只在主机上做）

1. **安装 Node.js**
   打开 https://nodejs.org/zh-cn ，下载 **LTS 版本**，一路点「下一步」装完。
2. **解压工作台**
   把压缩包解压到一个固定位置，比如 `D:\爆款工作台`。
   **路径里最好不要有空格。**
3. **第一次双击 `启动工作台.bat`**
   它会自动生成配置文件 `.env.local`，并用记事本打开。
   把大模型的 API Key 填进去，保存后关闭。
   - 默认用的是**通义千问**。在阿里云百炼控制台申请 API-KEY，填到 `AI_API_KEY=` 后面。
   - 拆解封面需要能看图的模型，默认的 `qwen-vl-max` 就可以。
4. **第二次双击 `启动工作台.bat`**
   - 第一次会自动安装依赖、构建，大约需要 2–5 分钟。
   - 完成后浏览器会自动打开工作台。
   - 窗口里会显示「同事打开」的地址，比如 `http://192.168.1.23:3000`，把它发给同事。
5. **防火墙提示**
   Windows 会弹出防火墙提示。请勾选「**专用网络**」，再点「允许访问」，否则同事打不开。
   如果点错或错过了，右键 `允许局域网访问.bat`，选择「以管理员身份运行」。

> Mac 当主机：双击 `启动工作台.command`，其他步骤一样。

## 二、日常使用

- **启动**：每天双击 `启动工作台.bat`。**黑色窗口不能关**，关了工作台就停了。
- **开机自动启动（可选）**：
  1. 按 `Win + R`，输入 `shell:startup`，回车，会打开「启动」文件夹。
  2. 把 `启动工作台.bat` 的**快捷方式**放进这个文件夹。
- **同事使用**：同事要和主机连同一个 Wi-Fi 或同一个网络，在浏览器里打开主机地址就行，不用装任何东西。
  > 主机的 IP 可能会变。可以在路由器后台给它固定一个 IP，或者每次看启动窗口里显示的地址。

### 五个页面

1. **入库拆解**：看到爆款，把链接（或者整段分享口令）粘贴到最上面的输入框里。
   工作台会自动抓取标题、正文、点赞收藏评论数、发布日期和封面，然后直接交给 AI 拆解。
   AI 会拆出 6 种积木：标题、封面、正文结构、开头钩子、结尾引导、话题标签。
   检查、修改、打分，删掉不要的，再点「确认入库」。
   - 同一篇笔记换了分享链接也能认出来，不会重复入库。
   - 抓不到时：换一个分享链接再试；或者在 `.env.local` 里填上 `XHS_COOKIE`（填法见 `.env.example`），然后重启；实在不行就手动粘贴标题和正文，封面截图直接 Ctrl+V。
2. **爆款库**：按类型、考试类别、关键词筛选，可以打分、复制、删除。
3. **考情**：做一个新考试之前，先在这里录入它的真实信息：科目、时间、特点、我们卖的资料。
   **生成时，考试相关的事实只从这里取，AI 不会自己编。**
4. **一键生成**：选好考试，一次出 1–5 版，每版都有标题、正文、标签和一张封面图（1080×1440）。
   文字可以直接修改，封面会跟着更新。点开封面看大图，右键保存。
5. **生成记录**：笔记发布一周左右，回填链接和数据。
   收藏超过 100 的，它借鉴过的积木会自动 +1 分，以后会被优先选用。

**冷启动建议：** 前两周每天入库 5–10 篇，库里攒到 50 篇以上，生成效果会明显变好。

## 三、调整效果

**提示词：** 用记事本直接改，保存后下一次拆解或生成马上生效，**不用重启**。

| 文件 | 管什么 |
|---|---|
| `prompts/拆解提示词.md` | 怎么拆爆款：拆哪些维度、槽位怎么替换 |
| `prompts/生成提示词.md` | 怎么写新笔记：风格、字数、禁用词、封面版式 |
| `prompts/默认/` | 原版备份。改坏了，从这里拷回去就行 |

**换模型：** 改 `.env.local` 里的配置，改完要**重启工作台**（关掉黑色窗口，再双击启动）。
- 只要是 OpenAI 兼容格式的接口都能用，比如通义千问、豆包、DeepSeek、Claude。
- 如果想让写文案换一个更会写的模型，填 `AI_TEXT_MODEL`。

## 四、数据与备份

所有数据都在 `data` 文件夹里：

| 位置 | 内容 |
|---|---|
| `data/workbench.db` | 数据库：爆款、积木、考情、生成记录全在这一个文件里 |
| `data/covers/` | 入库笔记的原封面图 |
| `data/backups/` | 每天第一次启动时自动备份一份，保留最近 30 天 |

- **换电脑**：把整个文件夹拷过去，在新电脑装好 Node.js，双击启动即可。
- **恢复备份**：
  1. 关掉工作台。
  2. 把 `data/backups` 里某一天的备份文件复制出来，改名为 `workbench.db`，替换掉 `data` 里原来的那个。
  3. 同时删掉 `data` 里的 `workbench.db-wal` 和 `workbench.db-shm` 两个文件。
  4. 重新启动。
- **建议**：每周把 `data` 文件夹往网盘里拷一份，防止电脑坏了。

## 五、升级到新版本

1. 关掉工作台。
2. 用新版本的文件覆盖旧文件，但**保留** `data` 文件夹和 `.env.local`。如果改过提示词，`prompts` 文件夹也要保留。
3. 双击启动。工作台会自动发现代码有更新并重新构建，大约 1 分钟。

## 六、常见问题

- **同事打不开**：按顺序检查：
  1. 主机的工作台窗口还开着吗？
  2. 同事和主机连的是同一个网络吗？
  3. 防火墙放行了吗？参考第一部分第 5 步。
- **想让在家的同事也能用**：
  1. 主机和同事都装上蒲公英或 ZeroTier 这类组网工具。
  2. **一定要**在 `.env.local` 里设置 `APP_PASSWORD`，然后重启工作台。
- **拆解或生成报错**：多半是 API Key 填错了，或者额度用完了。先检查 `.env.local`。
- **粘贴链接抓不到**：小红书偶尔会要求登录或验证。按上面的办法填 `XHS_COOKIE`。抓取失败时，页面会保存在 `data/debug/last-fetch.html`，可以发给技术同事排查。

## 技术说明（给技术同事看）

- 技术栈：Next.js 16 + Node.js 自带的 SQLite（`node:sqlite`，需要 Node 22.13 及以上）。没有原生依赖，Windows 上不用编译。
- 封面出图：用 `next/og`。中文字体是项目里自带的思源黑体 GB2312 子集（`fonts/`，SIL OFL 协议）。遇到生僻字，会尝试从 Google Fonts 补字。
- 积木检索：先取同一考试类别里「人工评分 + 原笔记热度」最高的积木，数量不够再用其他类别的高分积木补齐。配额在 `src/lib/retrieve.ts` 里调。
- 启动脚本 `scripts/start.mjs` 的流程：检查 Node 版本和配置 → 安装依赖（`.npmrc` 已设为国内 npmmirror 镜像）→ 发现 `src/` 有改动就重新构建 → 用 `next start -H 0.0.0.0` 监听局域网。
- 以后人多了，或者想脱离这台电脑独立运行：把 `src/lib/db.ts` 换成云数据库就行，其他代码不用动。
