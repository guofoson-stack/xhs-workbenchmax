# 小红书爆款工作台（本地版）

每天把找到的小红书爆款拆成「积木」存进库里。做新考试时，工作台会从库里自动搭配标题、封面、正文，一次生成好几版，封面直接出图。

**怎么用：** 找一台电脑当主机，双击启动，同事在浏览器里打开它的地址就能用。不需要服务器、数据库账号，也不需要备案。

```
📌 书签采集爆款 → AI 拆解入库 → 录考情 → 一键生成（标题 + 正文 + 封面图）→ 发布后回填数据 → 好积木自动加分
```

---

## 一、第一次安装（只在主机上做一次）

1. **安装 Node.js**：打开 https://nodejs.org/zh-cn ，下载 **LTS 版本**，安装时一路点「下一步」。
2. **解压**：把压缩包解压到一个固定位置，比如 `D:\爆款工作台`。路径里最好不要有空格。
3. **双击 `启动工作台.bat`**：第一次会自动安装依赖并构建，大约 2–5 分钟，完成后浏览器会自动打开工作台。
4. **创建管理员账号**：第一次打开会让你设一个姓名和密码，这就是管理员账号（只有管理员能进「设置」和「团队」）。升级前已经入库的素材都会记在管理员名下。
5. **填 API Key**：到「⚙️ 设置」点「用 DeepSeek」（或者通义千问），粘贴 API Key，再点「**保存并测试**」。
   - 显示 ✅ 就说明可以用了。
   - 看图那一项显示 ✅，说明拆封面时 AI 能自己识别封面。
6. **允许防火墙**：Windows 弹出防火墙提示时，勾选「**专用网络**」并点允许，不然同事打不开。
   错过了也没关系：右键 `允许局域网访问.bat`，选「以管理员身份运行」。

> 所有配置都在网页的「⚙️ 设置」里改，**改完马上生效，不用重启，也不用打开任何文件**。

## 二、日常使用

- **启动**：双击 `启动工作台.bat`。启动后出现的**黑色窗口不能关**，关掉工作台就停了。
- **开机自动启动（可选）**：按 `Win + R`，输入 `shell:startup` 回车，把 `启动工作台.bat` 的**快捷方式**放进打开的文件夹。
- **同事使用**：启动窗口里会显示「同事打开：http://192.168.x.x:3000」。同事连同一个网络，用浏览器打开这个地址，用你给的账号登录就行，不用装任何东西。登录一次保持 30 天。

### 账号和每日采集指标

- **开账号**：管理员到「👥 团队 → 成员管理」填姓名和初始密码，点添加，把姓名、密码和工作台地址发给员工。员工登录后可以在右上角自己改密码；忘了密码由管理员「重置密码」。
- **谁采集的**：每篇爆款入库时自动记在当前登录的人名下，生成记录和考情也一样。爆款库每张卡片会写「某某采集」，可以按采集人筛选。
- **指标**：默认每个员工周一到周五每天采集 1 篇，在「团队 → 指标设置」里改篇数和考核日，填 0 就是暂停考核。管理员账号不考核。
- **员工看到的**：首页和顶部显示「今日采集 0/1」，没完成是红色，完成变绿。员工看不到「设置」和 API Key。
- **管理员看到的**：首页显示「今天团队 x/y 人完成」；「团队」页可以看今天谁完成了、谁还没完成，本周每人每天采集几篇（绿色达标、红色没达标，可以翻看前几周），以及本月采集篇数、达标天数、采集笔记的平均赞藏（看找的是不是真爆款）、被模仿次数（看采集的素材有没有用）。
- **离职**：在成员管理里点「停用」，TA 就登录不了了，采集过的素材和记录都保留。
- **书签采集没登录也不会丢**：员工没登录时点了书签，会先跳到登录页，登录完自动回到采集页继续拆解。

### 页面说明

1. **入库拆解**
   - **📌 书签一键采集（推荐）**：第一次打开这个页面时，按页面上的说明，把「📌 存到爆款工作台」按钮拖到浏览器书签栏。以后在小红书网页版点开一篇笔记，再点一下这个书签，工作台会自动打开，填好标题、正文、点赞收藏评论、日期、封面，并直接开始拆解。每台电脑要各自拖一次书签。
   - **粘贴链接**：这种方式是工作台在后台去抓小红书，常常会被小红书拦截。被拦了就改用书签。
   - 拆解完检查一下：可以修改、打分、删掉不要的积木，然后点「确认入库」。同一篇笔记不会重复入库。
2. **爆款库**：可以按类型、考试类别、**场景**、关键词筛选，也可以打分、复制。
   - **场景**：这篇爆款是哪个阶段的选题，比如公告解读、报名指导、备考方法、考前冲刺、考后估分、面试、企业文化时政、上岸经验。新拆解的笔记会自动标注；旧素材点「一键补标签」就行。标得不对，在卡片上直接改。
3. **考情**：做一个新考试之前，先在这里准备好它的考情。生成时，考试相关的事实只从这里取，AI 不会自己编。
   - **🔍 AI 搜索考情**：输入考试名（最好带上年份和单位全称），点「搜索整理」。工作台会联网搜公告、大纲、时间节点，整理好填进表单，判断**当前阶段**（比如「笔试已考完，等出成绩」），并附上来源链接和可信度。你检查后点保存。
   - 用的是 DeepSeek 的联网搜索接口（每 1000 次约 5 元），搜一次考情大约用 4 次搜索。大模型用的是 DeepSeek 时，不用另外配置。
   - 生成笔记时会参考「当前阶段」，比如考试已经考完，就不会再写"抓紧备考"。
4. **一键生成**：选好考试，一次出 1–5 版，**每一版都会指定一篇爆款来模仿**。
   - **选题场景**：默认按考情阶段自动判断，比如"4 天后开始报名 → 报名指导"，然后优先挑同场景的爆款；也可以手动指定。
   - **模仿强度**：高度模仿（默认，标题和封面保留原句式，只换考试信息，正文按原结构写）/ 结构借鉴 / 自由发挥。
   - **指定模仿**：可以直接选库里的某一篇，几版都照着它写。
   - 每版上方会显示「📎 模仿：原爆款标题 · 标题模板 · 借鉴度」。高度模仿时，借鉴度低于 50% 的标题会自动返工一次。
   - **🔄 不满意？**：每一版都可以单独返工，有这几种方式：
     - 选择只改标题、封面或正文，也可以整版重写
     - 点常用意见（更口语、更短、更有紧迫感、去掉AI味……），或者自己写意见
     - 勾选「换一篇爆款来模仿」
     - 点「✨ 换 5 个标题」，用 5 个不同的爆款模板各出一个标题，挑一个点一下就换上

     改坏了点「↩ 撤销」。
   - **发布前检查**：每版下面自动标出容易限流的词（导流、交易、极限词、"保过/押题"这类承诺），能自动改的点「一键替换」。自己发现的新限流词，在「⚙️ 设置 → 违禁词」里加上。生成时也会提前告诉 AI 避开这些词。
   - **📦 下载发布包**：封面图 + 标题正文 txt 打成一个压缩包，传到手机直接发。
   - 内容可以直接修改；点封面看大图，右键保存。
5. **生成记录**：笔记发布后，回来填上数据。收藏超过 100 的，它借鉴过的积木会自动 +1 分。
6. **👥 团队**（管理员）：成员管理、每日指标、完成情况，见上面「账号和每日采集指标」。
7. **⚙️ 设置**（管理员）：在这里换模型、换 Key、设置自动更新和违禁词。

## 三、自动更新（设置一次，以后不用再下载安装包）

在「⚙️ 设置 → 自动更新」里填好更新源（GitHub 仓库）。以后每次双击启动，工作台会自动检查有没有新版本，有就下载并更新。

- 只会替换程序文件。**配置、数据、你自己改过的提示词都不会被动。**
- 连不上 GitHub 的时候，会继续用当前版本照常启动。

---

## 四、配置、数据和提示词放在哪

都在 **`C:\Users\你的用户名\爆款工作台数据\`**，不在程序文件夹里，所以换版本、自动更新都不会丢：

| 位置 | 内容 |
|---|---|
| `设置.json` | 在网页设置页里改，不用手动编辑 |
| `data\workbench.db` | 数据库：爆款、积木、考情、生成记录 |
| `data\covers\` | 入库笔记的原封面 |
| `data\backups\` | 每天自动备份一份，保留 30 天 |
| `自定义提示词\` | 想改提示词时，把程序文件夹 `prompts\` 里的文件复制到这里再改。会优先使用这里的版本，自动更新不会覆盖 |

- **换电脑**：把整个「爆款工作台数据」文件夹复制到新电脑的同一个位置，装好 Node.js，再解压程序双击启动就行。
- **恢复备份**：
  1. 关掉工作台。
  2. 把 `data\backups` 里某一天的备份改名为 `workbench.db`，替换掉 `data\workbench.db`。
  3. 删掉 `workbench.db-wal` 和 `workbench.db-shm` 这两个文件。
  4. 重新启动。
- **从旧版升级**：第一次启动新版时，会自动把旧版程序文件夹里的 `.env.local` 和 `data` 搬过来。

## 五、常见问题

- **同事打不开**：按顺序检查：主机的窗口还开着吗？同事和主机在同一个网络吗？防火墙放行了吗？
- **拆解或生成报错**：去「⚙️ 设置」点「保存并测试」，页面会告诉你是 Key 不对、余额不足，还是地址或模型名不对。
- **点了书签没反应**：先确认已经点开了笔记详情页，并且主机上的工作台正开着。
- **书签采集后提示连不上**：主机 IP 变了。在新地址打开工作台，再拖一次书签。
- **想让在家的同事也能用**：主机和同事都装上蒲公英或 ZeroTier，用各自的账号登录。员工密码别设太简单。
- **管理员密码忘了**：在主机上双击 `重置密码.bat`，选你的名字、输新密码就行，工作台不用关。

## 技术说明（给技术同事看）

- 技术栈：Next.js 16，加上 Node.js 自带的 SQLite（`node:sqlite`，需要 Node 22.13 以上），没有原生依赖。
- 配置文件放在 `WORKBENCH_HOME`（默认是 `~/爆款工作台数据`）。代码在每次请求时读取 `设置.json`，所以改了立即生效。
- 启动脚本是 `scripts/start.mjs`，流程依次是：
  1. 迁移旧版的配置和数据
  2. 自动更新（`scripts/update.mjs`：调用 GitHub API 取 HEAD 和 zipball，覆盖程序文件，跳过 node_modules、.next、data）
  3. 依赖有变化时重新执行 npm install
  4. `src` 有改动时重新构建
  5. 用 `next start -H 0.0.0.0` 启动
- 书签采集的代码在 `src/lib/bookmarklet.ts`：读取笔记页的 `window.__INITIAL_STATE__`，带上 `#xhs=` 打开入库页。
